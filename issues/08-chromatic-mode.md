# 08 — Chromatic mode

> Type: AFK · Source: docs/PRD.md · Stories: 15, 16

## What to build

A mode toggle that flips the hero card to chromatic mode (with a tuning-fork motif), where the app names the nearest note to whatever is played and shows its cents deviation — reusing the same detection and deviation meter, with no fixed string targets. The flip cross-fades under Reduce Motion.

## Acceptance criteria

- [ ] Toggling flips the hero to chromatic mode and names the nearest note for any pitch, with cents deviation
- [ ] The flip degrades to a cross-fade under Reduce Motion
