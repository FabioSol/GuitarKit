# 21 — Circle hub cross-links

> Type: AFK · Source: docs/PRD.md · Stories: 46, 47, 49

## What to build

Promote the circle from explorer to hub by wiring its details panel into the kit: the diatonic chord chips open in the Chords tool with that chord loaded, and "View scale" opens in the Scales tool. These cross-links drive the rotary nav to the target tool and preserve each tool's state so returning to the circle is continuous.

## Acceptance criteria

- [ ] Tapping a diatonic chord chip opens it in Chords; "View scale" opens it in Scales, each with context loaded
- [ ] Cross-links drive the rotary nav and preserve each tool's state on return
