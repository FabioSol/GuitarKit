# 17 — Harmony domain model

> Type: AFK · Source: docs/PRD.md · Stories: —

## What to build

The pure harmony layer: circle-of-fifths relationships, key signatures, relative minors, the seven diatonic triads per key, scale/mode note sets, and chord-quality → interval/note-set resolution (the rich quality set). No UI — deterministic and unit-tested, this feeds the circle, scales, and chords tools.

## Acceptance criteria

- [ ] Each key resolves to the correct signature, relative minor, and seven diatonic triads
- [ ] Scales/modes and chord qualities resolve to the correct note sets (including extended/altered qualities)
- [ ] Behavior covered by unit tests through the public interface

## Blocked by

None - can start immediately.
